# acao-boop.github.io

Andrew Cao's home page: https://acao-boop.github.io/

It introduces Andrew and lists his work. Each project is its own repository and its own GitHub Pages site under this address, for example https://acao-boop.github.io/ante-possessive-lives/.

- `site/` is the whole page, plain HTML, CSS and a few lines of JavaScript. Every push to `main` publishes it through `.github/workflows/pages.yml`.
- `tools/preview/` previews unpublished edits over the live page.
- New projects start from https://github.com/acao-boop/project-template.
